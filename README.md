# 5-Day-GenAI-Google-Project
Energy saving project utilizing Googles GenAI tools

My team and I worked on this project. I created the Agent that fetches data and gives suggestions to user  on energy saving actions for their home. I also created the youtube overview of our project with the help of my team mate. 

# Watt-Saver

This is the [Gen AI Intensive Course Capstone 2025Q1 Project](https://www.kaggle.com/competitions/gen-ai-intensive-course-capstone-2025q1) which is part of [5-Day Gen AI Intensive Course with Google](https://rsvp.withgoogle.com/events/google-generative-ai-intensive_2025q1)
Participants collaborated on applying Generative AI to the problem of understanding and optimizing residential energy consumption using real-world and simulated datasets.

---

## Project Overview

Turn insights into action. Watt-Saver uses Gemini to analyze personal energy data and suggest behavior, variable vs fixed rate, device, and time-shifting optimizations.
